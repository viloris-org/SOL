## 概述

参考 `/home/rownix/Downloads/busybox-1.38.0/` 的实现，成功为 Lyra shell 复刻了大部分常用命令。从原来的 8 个命令扩展到 **31 个内建命令**。

## 实现的命令分类

### 1. 基础命令 (8个)
原有命令保持不变：
- `echo`, `ls`, `cd`, `pwd`, `exit`, `which`, `clear`, `reset`

### 2. 文件操作 (6个) ✨ 新增
- **`cat`** - 显示文件内容
  - 支持标志: `-n` (行号), `-E` (显示行尾)
  - 支持多文件和stdin输入

- **`cp`** - 复制文件/目录
  - 支持标志: `-r` (递归), `-f` (强制), `-v` (详细输出)
  - 支持目录递归复制

- **`mv`** - 移动/重命名文件
  - 支持标志: `-f` (强制), `-v` (详细输出)
  - 正确处理多源文件到目录

- **`rm`** - 删除文件/目录
  - 支持标志: `-r` (递归), `-f` (强制), `-v` (详细输出)
  - 安全的错误处理

- **`mkdir`** - 创建目录
  - 支持标志: `-p` (创建父目录), `-v` (详细输出)

- **`touch`** - 创建文件或更新时间戳
  - 使用 `filetime` crate 实现

### 3. 文本处理 (6个) ✨ 新增
- **`grep`** - 文本搜索
  - 支持标志: `-i` (忽略大小写), `-v` (反向匹配), `-n` (行号), `-c` (计数)
  - 支持多文件和stdin

- **`head`** - 显示文件开头
  - 支持标志: `-n N` (行数，默认10)

- **`tail`** - 显示文件结尾
  - 支持标志: `-n N` (行数，默认10)

- **`wc`** - 统计字数
  - 支持标志: `-l` (行数), `-w` (单词), `-c` (字符), `-m` (字节)

- **`sort`** - 排序
  - 支持标志: `-r` (反向), `-u` (去重), `-n` (数值排序)

- **`uniq`** - 去重
  - 支持标志: `-c` (计数), `-d` (仅重复), `-u` (仅唯一)

### 4. 系统工具 (11个) ✨ 新增
- **`env`** - 显示环境变量
- **`basename`** - 提取文件名
- **`dirname`** - 提取目录路径
- **`sleep`** - 延时（支持小数秒）
- **`date`** - 显示日期时间（支持自定义格式）
- **`true`** - 返回成功
- **`false`** - 返回失败
- **`whoami`** - 显示当前用户
- **`uname`** - 系统信息（支持 `-a`, `-s`, `-n`, `-r`, `-v`, `-m`）

## 使用示例

### 文件操作
```bash
λ cat file.txt                    # 显示文件
λ cat -n file.txt                 # 带行号显示
λ cp file.txt backup.txt          # 复制文件
λ cp -r dir1 dir2                 # 递归复制目录
λ mv old.txt new.txt              # 重命名
λ rm -rf directory                # 删除目录
λ mkdir -p dir1/dir2/dir3         # 创建嵌套目录
```

### 文本处理
```bash
λ grep "error" log.txt            # 搜索文本
λ grep -i "ERROR" log.txt         # 忽略大小写
λ head -n 10 file.txt             # 前10行
λ tail -n 20 file.txt             # 后20行
λ wc file.txt                     # 统计行/词/字符数
λ sort file.txt                   # 排序
λ sort file.txt | uniq -c         # 去重并计数
```

### 管道组合
```bash
λ cat file.txt | grep "pattern" | wc -l
λ ls | grep txt | sort
λ cat data.txt | sort | uniq
```

### 系统信息
```bash
λ whoami                          # 当前用户
λ date                            # 当前时间
λ uname -a                        # 系统信息
λ env                             # 环境变量
λ basename /path/to/file.txt     # → file.txt
λ dirname /path/to/file.txt      # → /path/to
```
