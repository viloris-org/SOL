## New Commands (23)

### File Operations (6)
- cat: concatenate and display files (-n, -E flags)
- cp: copy files/directories (-r, -f, -v flags)
- mv: move/rename files (-f, -v flags)
- rm: remove files/directories (-r, -f, -v flags)
- mkdir: create directories (-p, -v flags)
- touch: create files or update timestamps

### Text Utilities (6)
- grep: pattern matching (-i, -v, -n, -c flags)
- head: show first N lines (default 10)
- tail: show last N lines (default 10)
- wc: count lines/words/chars/bytes (-l, -w, -c, -m flags)
- sort: sort lines (-r, -u, -n flags)
- uniq: deduplicate lines (-c, -d, -u flags)

### System Utilities (11)
- env: display environment variables
- basename: strip directory from path
- dirname: extract directory from path
- sleep: delay execution (supports fractional seconds)
- date: display date/time (custom format support)
- true: return success
- false: return failure
- whoami: show current user
- uname: system information (-a, -s, -n, -r, -v, -m flags)

## Implementation

New modules:
